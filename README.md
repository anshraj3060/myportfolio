# Ansh Raj | Personal Portfolio Website

A personal portfolio website built by Ansh Raj, a first-year B.Tech (CS & AIML) student at Bosscoder School of Technology, Bengaluru. It showcases my education, skills, projects, hobbies and achievements.

## Live Demo

**Live link (Vercel): https://vercel.com/byte-force-bdc4/myportfolio

## Sections

- Home
- About Me
- Education
- Skills (with progress bars)
- Projects
- Hobbies
- Achievements
- Contact (with form)

## Features

- Sticky navigation bar with icons and smooth scrolling
- Skill progress bars
- Project and achievement cards with hover effects
- Contact form with input validation

## Technologies Used

- HTML5
- CSS3
- Font Awesome (icons)
- Visual Studio Code
- GitHub (version control)
- Vercel (hosting)

## How to View

You can view this project in two ways:

**1. Online (Vercel)**
Open the live link above in any modern browser. No setup needed.

**2. From GitHub (run locally)**
1. Open this repository on GitHub.
2. Click **Code → Download ZIP**, or clone the repository.
3. Extract the folder and open `index.html` in any modern browser.

Keep `index.html`, `style.css` and the `image` folder together in the same folder, otherwise styles and images will not load.

## Note

- I have not learned JavaScript yet, so the contact form validation uses HTML's built-in attributes (`required`, `type="email"`, `minlength`).
- The contact form is a demo. There is no backend, so messages are not actually sent.
- Dark mode and responsive design are not added yet and will be added later.
