Fridge-To-List

Fridge to List is a local-first web app that reads one to four photos of your fridge, freezer or pantry and turns them into an editable grocery list. The eyes doing the reading are an open-weight vision model — Gemma 3 (gemma3:4b) — running on your own machine through Ollama. No cloud, no account, no API key, no photos leaving the building.

Technologies: HTML, CSS, JavaScript
